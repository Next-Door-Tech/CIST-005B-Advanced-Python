Due Feb 24 by 11:59pm | Points 10 | Submitting a file upload | Available until Feb 26 at 11:59pm

## Objective:
In this lab, you will practice generating and implementing creative project ideas focused on making use of sorting algorithms.


## The Prompt
Implementing a deck and hand of playing cards. Show the ability to properly go through and sort the hand or deck of cards. Use one of two algorithms, an algorithm that prioritizes space and one that prioritizes time.


## Building
Implement your card game alongside your lab teams. While designing your code, keep an eye out for edge-cases and incorrect input locations that may cause crashes if not properly handled and avoid them. The user interface should be clean and clearly inform the user of the current state of the game as well as how to provide proper input, but it does not necessarily have to be a GUI.


## Rubric
* Game Code (35%) - Ensure sorting algorithm is in place to keep hand sorted properly along with game logic.
* Testing and Debugging (10%) - Thorough testing with a variety of test cases, code doesn't crash with unexpected input.
* Commenting and Structure (5%) - Code is well-organized, with meaningful variable names, professional comments, and clear logic flow.
* Demo and Oral Questions (50%) - Once your code is complete, you will demo the working code to me during lab time and each member of the lab group will be asked questions to ensure they understand how their code functions.
